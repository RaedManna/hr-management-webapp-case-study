# HR Management Web Application Case Study

A professional case study of a full-stack HR management web application I worked on during my internship at **AIstudio** in Ankara, Türkiye.

The project was designed to support internal HR workflows such as employee management, leave requests, payroll, attendance tracking, dashboards, reports, and role-based access for different user levels.

> Note: This repository is a case study only. Private company source code, internal data, credentials, and confidential implementation details are not included.

---

## Overview

During my internship at AIstudio, I worked as a **Full-Stack Developer Intern** on a complete HR management web application.

The system was built using a modern full-stack architecture with a React/Vite frontend, FastAPI backend, and Supabase for backend/database functionality.

The application supported multiple user roles, including:

- Employees
- HR management users
- CEO-level users
- Admin-level functionality

The goal of the project was to create a centralized web platform for managing HR operations and internal business workflows.

---

## Tech Stack

**Frontend:** React, Vite
